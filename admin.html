إدارة ملفات التحميل

هذه الصفحة لك فقط. ادخل بمفتاح GitHub الخاص بك (يُحفظ في هذا المتصفح فقط).

كيف أحصل على المفتاح؟ (مرة واحدة فقط)
  1. افتح github.com/settings/personal-access-tokens/new
  2. Token name: professor-upload — Expiration: اختر No expiration أو سنة.
  3. Repository access: Only select repositories واختر professor-tv-download.
  4. Permissions ← Repository permissions ← Contents: اختر Read and write.
  5. اضغط Generate token وانسخ المفتاح والصقه هنا.
